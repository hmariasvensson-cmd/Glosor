// Ordlista för franska. Rader som börjar med // är kommentarer och tas bort vid bygget.
//
// Format, en rad per ord:
//   franska|svenska|genus|exempel på franska|exempel på svenska|ursprung|ordagrant
// Hakparentes i den franska exempelmeningen markerar luckan i meningsövningen:
//   Nous [rions] beaucoup ensemble.
// Saknas hakparentes letar programmet själv efter ordet i meningen.
// Genus: m, f, mpl, fpl eller tomt. Ursprung får innehålla <b>fetstil</b>. Ordagrant är valfritt och används för fraser: ordet för ordet på svenska, t.ex. <b>avoir</b> ha · <b>l'air</b> luften → "ha luften".
// En rad som börjar med # startar ett nytt avsnitt:  #id|Namn som visas, eller #id|Namn|bok för kapitel ur läroboken
// Avsnittets id och ordets franska form används som nycklar för sparade framsteg,
// så ändra dem inte i efterhand (ändra gärna svenska, exempel och ursprung).
